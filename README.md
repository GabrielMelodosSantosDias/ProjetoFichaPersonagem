Hero Character Sheet — Part 1

Individual HTML and CSS project developed for the P1 assessment, featuring an RPG-style character profile inspired by Gabriel.

## Character

Name: Gabriel  
Class/Profile: Athlete • Adventurer • Tech  
Visual Theme: Futuristic RPG interface with a dark background and neon blue highlights.

## Structure

- About the Hero
- Attributes & Skills
- Inventory & Achievements
- Contact the Guild

The project uses semantic HTML elements such as `header`, `nav`, `main`, `section`, and `footer`, along with an external CSS stylesheet, Flexbox, CSS Grid, `:root` variables, HTML/CSS attribute bars, and media queries.

## Responsiveness

- Mobile: Inventory displayed in 1 column.
- Tablet: Inventory displayed in 2 columns.
- Desktop: Inventory displayed in 3 columns.

## UI/UX Design Decisions

Visual Hierarchy: The hero's name and introduction appear first, followed by organized sections with highlighted titles and icons.

Contrast and Readability: A dark background with light-colored text and neon blue accents for headings, attribute bars, and interactive elements.

Consistency: Cards share the same borders, spacing, rounded corners, and color palette. Attribute bars follow a consistent visual style.

Proximity and Grouping: Each attribute's name, icon, value, and progress bar are grouped within the same section.

Affordance and Feedback: Navigation menus, buttons, links, and cards include `hover` and `focus` states to provide visual feedback during interactions.

## How to Run

Open the `index.html` file in any modern web browser.
